Na+ / K+ 시뮬레이션 v5

실행
Python 3가 설치된 컴퓨터에서:
  python ion_simulation_v5.py
Windows에서 python 명령이 안 되면:
  py ion_simulation_v5.py
표준 라이브러리 tkinter를 사용하므로 별도 pip 설치가 필요 없습니다.
Colab이 아닌 로컬 데스크톱에서 실행하세요. Python 설치에 Tcl/Tk가 포함되어야 합니다.

변경 사항
- 입자는 N(Na+)과 K(K+)로 표시합니다.
- 가로 칸 간격 18px, 세로 14px로 가로를 약간 넓혔습니다.
- 50×50 격자와 가로/세로 스크롤을 유지합니다. 확대/축소도 가능합니다.
- 이동 주기는 0.01초입니다.
- 화면 전체 삭제를 없애고, 기존 Canvas 문자 중 바뀐 칸만 갱신하여 깜빡임을 줄입니다.
- 2~4번 실험의 세포 안 이온 수를 매 이동마다 기록하고 별도 그래프 창에 표시합니다.
- 1번 실험은 입자 수 기록 및 이벤트 기록에서 제외합니다.
- 그래프: Na+ 파랑, K+ 초록. 가로축은 일시정지를 제외한 실행 시간(초)입니다.
- 시간축 아래: Na 통로 파랑, K 통로 초록, 펌프 빨강으로 개방/중지를 표시합니다.
- 3/4번 시작 시 K 통로 1개 개방을 기록합니다. 4번 시작 시 펌프 개방도 기록합니다.
- 실제 계산 결과를 그립니다. 참고 그림의 곡선 형태를 강제로 재현하지 않습니다.

조작
1-4: 실험 선택. 선택 시 초기 배치와 기록이 초기화됩니다.
S: 모든 이동과 자동 개폐 시간 및 그래프 시간을 일시정지/재개.
N: Na 통로 17개 열기/닫기.
K: K 통로 17개 열기/닫기. 닫기 시 최초의 1개는 열어 둡니다.
   그래프에는 '중지 (1/17) · 1개 유지'로 표시합니다.
M: Na 통로만 정확히 15초 → K 통로만 정확히 18초 → 종료 상태로 복귀.
   4번은 종료 후 최초 K 통로 1개를 유지합니다. 3번은 모두 닫습니다. 0.01초 이동 주기와 개폐 타이머는 독립적입니다.
   M 진행 중 N/K/M은 잠깁니다. S, P는 사용할 수 있습니다.
P: 4번 실험의 16개 펌프 전체 작동/중지. 펌프의 Na/K 대기 상태는 유지됩니다.
G: 그래프 창 열기. 2-4번 실험 선택 시에도 자동으로 열립니다.
R: 현재 실험 초기화. 정지 상태는 유지됩니다.
Esc: 종료.
키가 안 먹으면 영문 입력으로 전환하세요. 화면 버튼으로도 조작할 수 있습니다.
그래프 창의 X는 그래프 창만 숨깁니다. G로 다시 열 수 있습니다.

그래프와 저장
가로축: 일시정지를 제외한 실행 시간(초). 세로축: 세포 안(x<25)의 이온 개수.
그래프 아래 이벤트 표에서 발생 시간과 정확한 통로 개방 개수를 확인할 수 있습니다.
시간이 길어지면 가로 스크롤이 늘어납니다. '최근 시점 따라가기'를 끄면 과거를 볼 수 있습니다.
가까운 이벤트 설명은 서로 다른 줄에 표시되며, 공간이 부족하면 세로 스크롤로 볼 수 있습니다.
'SVG + CSV 저장' 버튼은 같은 위치에 세 파일을 저장합니다.
  이름.svg: 브라우저에서 열 수 있는 그래프
  이름_counts.csv: time_seconds, Na_inside, K_inside
  이름_events.csv: time_seconds, kind, event
실험 전환, R 초기화, 프로그램 종료 시 이전 기록은 메모리에서 사라집니다.
보관하려면 그 전에 저장하세요. S로 멈춘 상태에서도 저장할 수 있습니다.

실험과 모형
1: 막 없는 자유 확산. 전체에 Na/K를 무작위 배치하며 좌우 농도 조건을 적용하지 않습니다.
중앙 표시 열과 세포 안/밖 집계 없이 전체 이온 수만 표시하고 기록하지 않습니다.
2: 통과할 수 없는 막.
3: Na 통로 17개와 K 통로 17개. 최초 K 통로 1개 개방.
4: 3번 + 펌프 16개. 펌프는 처음부터 작동.
막은 x=24와 x=25 사이에 있는 별도 표시 열입니다. 이온 공간은 50×50칸입니다.
초기 배치는 실행/초기화마다 달라집니다(SEED=None).
재현이 필요하면 Python 파일의 SEED를 42 같은 정수로 바꾸세요.
상하좌우 선택은 각 25%이며, 한 방향으로 치우치는 힘은 추가하지 않았습니다.
한 칸에 이온 1개. 각 이온은 0.01초마다 상하좌우 중 하나를 동일 확률로 선택합니다.
벽, 닫힌 막, 다른 이온이 있으면 제자리에 있습니다.
이동 전 배치를 기준으로 빈칸을 향한 이동만 허용합니다.
같은 빈칸에 여러 이온이 가려 하면 하나만 무작위로 이동합니다.
통로는 해당 이온의 양방향 통과만 허용합니다.

펌프
펌프 행 y의 안쪽 결합칸: (24,y-1), (24,y), (24,y+1).
세 칸 모두 동시에 Na이면 3개를 밖으로 수송하고 K 대기 상태로 바뀝니다.
바깥쪽 결합칸: (25,y-1), (25,y), (25,y+1).
이 중 2칸 이상이 K이면 2개를 안으로 수송하고 Na 대기 상태로 돌아옵니다.
이온은 누적 결합하지 않으며 필요한 수가 동시에 모여야 합니다.
배출 위치는 반대편 바로 옆 3×3 구역의 빈칸을 무작위로 선택합니다.
빈칸이 부족하면 기다립니다. 펌프마다 결합과 수송을 별도 틱에 수행합니다.
조건이 충족되면 실제 이온 3개 또는 2개를 결합하고, 다음 틱부터 배출 공간을 확인하여 수송합니다.
결합 중인 이온은 현재 위치에 고정되며 자유 확산하지 않습니다.
배출 공간이 부족하면 결합 상태를 유지합니다. P로 멈춰도 결합 상태를 유지합니다.
확산 후 펌프를 처리하므로 같은 틱에 확산한 이온이 펌프에 추가로 수송될 수 있습니다.
펌프는 통로 개폐와 독립적으로 동작합니다. P로 중지한 동안 수송하지 않습니다.
막의 P/Q는 각각 Na/K 대기 상태, 소문자 p는 펌프 중지입니다.

설정: Python 파일 위쪽
STEP_MS = 10: 이동 주기(ms)
NA_SECONDS = 15, K_SECONDS = 18: M의 개방 시간(초)
INITIAL_COUNTS = (125, 375, 375, 125)
2~4번에서 순서: 안 Na, 안 K, 밖 Na, 밖 K.
1번에서는 좌우 수를 합쳐 Na 500개와 K 500개를 전체 공간에서 무작위로 배치합니다. 각 반쪽 합은 1250 이하여야 합니다.
기본값은 관찰용 임의 값이며 실제 세포 농도의 정량 재현이 아닙니다.
전기력, 음이온, 물, 막전위, ATP 소모, 전압 의존성 개폐는 계산하지 않습니다.
따라서 실제 활동 전위나 실제 세포의 평형을 정량적으로 재현하지 않습니다.

v4 추가 안내
4번 실험의 막 50칸 전체를 Na 통로 17칸, K 통로 17칸, 펌프 16칸으로 채웁니다.
0~47행은 Na/K/펌프를 순서대로 반복하며, 48/49행은 Na/K 통로입니다.
3번에서는 펌프 위치 16칸이 통과 불가능한 막으로 남습니다.

화면 위쪽 통계
- Na+ 통로를 통한 누적 통과 수: 안→밖, 밖→안 합계.
- K+ 통로를 통한 누적 통과 수: 안→밖, 밖→안 합계.
- 펌프의 Na+ 배출, K+ 유입: 결합 횟수가 아닌 실제 수송 완료한 이온 수.
- Na+와 실제 결합 중인 펌프 수, K+와 실제 결합 중인 펌프 수.
통로 수치는 고유 입자 수가 아닙니다. 같은 입자가 왕복하면 2번 집계합니다.
결합 중인 펌프 수는 대기 중인 펌프 수와 다릅니다. 결합이 없으면 0으로 표시됩니다.
모든 누적 집계는 실험 변경 또는 R 초기화 시 0으로 돌아갑니다.

시간과 성능
물리 이동 간격은 0.01초(초당 100회)이며 화면은 약 30회/초, 그래프는 약 5회/초 갱신합니다.
화면 갱신 사이에도 여러 번의 이동을 계산하여 불필요한 다시 그리기를 줄입니다.
M의 15초/18초 타이머와 일시정지 처리는 유지됩니다. 실제 속도는 컴퓨터 성능에 영향을 받습니다.

가장자리
x,y가 0~49 범위를 벗어나는 이동은 거부하여 제자리에 머뭅니다.
반대편으로 이어지는 주기적 경계(워프)는 없습니다. 네 변 전체에서 확인하는 검증이 포함됩니다.


v5: PNG 저장 및 M 시간 변경
M: Na+ 통로 15초 개방 → Na+ 닫고 K+ 통로 18초 개방 → 종료(총 33초).
4번 실험의 종료 상태는 Na 통로 모두 닫힘, K 통로 1개 개방입니다.
그래프에는 종료 시 K 통로 중지 (1/17) 및 1개 유지로 기록됩니다.
S로 일시정지하면 타이머도 멈춥니다.

그래프 창에서 'PNG 저장' 버튼으로 그림을 저장할 수 있습니다.
스크롤 밖의 전체 그래프, 범례, 시간축, 개방/중지 표시를 포함하며 2배 해상도로 저장합니다.
SVG/CSV 저장 버튼도 그대로 사용할 수 있습니다.
PNG 저장을 위한 최초 1회 설치:
  python -m pip install pillow
Windows에서 python 대신 py를 쓰는 경우:
  py -m pip install pillow
Pillow가 없어도 시뮬레이션과 SVG/CSV 저장은 사용할 수 있습니다.
PNG 한국어 폰트는 Windows 맑은 고딕, macOS 한국어 폰트, Linux Noto/Nanum 순서로 찾습니다.
프로그램 옆에 NotoSansKR-Regular.ttf 파일을 두면 우선 사용합니다.
한국어 폰트가 없으면 PNG의 설명만 영문으로 대체하여 글자 깨짐을 방지합니다.
